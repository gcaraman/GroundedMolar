# MolarMap privacy statement

Effective date: 26 August 2026

MolarMap is an offline desktop application. It does not collect, transmit, sell, or share personal data. It contains no telemetry, analytics, advertising, account system, update checker, or network service.

The application reads only the Grounded save file or saves folder selected by the user. It does not modify the selected save. Preferences are stored locally in `%LOCALAPPDATA%\MolarMap\settings.json`. Temporary decoder files are created locally while processing a save and are removed after processing.

The optional “View the community guide” action displays the destination address and requires confirmation before Windows opens that address in the user’s default browser. The browser and destination website operate under their own privacy terms; MolarMap does not receive information from that visit.

For privacy or support questions, use the support contact published on the official MolarMap Microsoft Store or Nexus Mods listing.
